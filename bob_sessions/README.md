# IBM Bob Session Evidence

This directory contains the IBM Bob session reports and screenshot evidence
retained from the ChangeLens development workflow.

IBM Bob was used as a genuine development and verification assistant
throughout the project. Evidence is organized by team member and session.

---

## Structure

```text
bob_sessions/
├── member_1/
│   ├── session_01/   Repository and architecture orientation
│   ├── session_02/   Testing and regression analysis
│   ├── session_03/   Analyzer/backend robustness audit
│   └── session_04/   Focused production development
└── member_2/
    ├── session_01/   Documentation and developer-workflow investigation
    ├── session_02/   Documentation gap identification and correction
    ├── session_03/   Frontend usability improvement
    └── session_04/   Final repository and submission verification
```

---

## Session Contents

Each session folder contains:

- `session_report.md` — a written record of the task, findings, changes made,
  and verification result for that session
- `bob_session_NN_response.png` — a screenshot of IBM Bob's response
- `bob_session_NN_usage.png` — a screenshot of the IBM Bob usage panel
  (included where available)

## Evidence Retention Principle

Session evidence is retained to demonstrate that IBM Bob was used as a
genuine development assistant, not as a branding claim.

Each session report describes:

- the task objective
- what IBM Bob was asked to do
- what was actually changed
- verification results

No session report fabricates contributions, test results, or capabilities.
